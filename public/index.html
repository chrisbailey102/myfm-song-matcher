MyFM Song Matcher

Run npm run start:ui from the project folder (with .env containing Spotify credentials). You can pick your Excel file here or keep using the CLI.

Enrich from Excel

Choose your .xlsx (Artist + Title columns). This calls Spotify for each row; large lists can take several minutes. When it finishes, your browser downloads catalog_enriched.csv and a copy is saved under out/ for the table below.
